# ModaConnect — Demo

Demo estático para publicar en Cloudflare Pages.

## Archivos
- index.html
- styles.css
- script.js

## Publicación en Cloudflare Pages
1. Sube esta carpeta a un repositorio de GitHub.
2. En Cloudflare: Workers & Pages → Create application → Pages → Connect to Git.
3. Selecciona el repositorio.
4. Para este demo no necesitas build command.
5. Directorio de salida: `/` (o deja la configuración automática).
6. Publica y Cloudflare generará una URL `*.pages.dev`.

## Importante
En `script.js`, cambia el número de WhatsApp de ejemplo:
`5210000000000`
por el número real de la boutique, incluyendo código de país.
